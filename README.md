- YouTube Downloader in Flask
- A simple web application to download YouTube videos, built with Flask and Python.
Users can enter a YouTube video URL and download the video directly from their browser.

- Features
- Download YouTube videos by URL
- Simple and clean web interface
- Built with Flask and Python
- Getting Started
- Prerequisites
- Python 3.7 or higher
Git
Installation
Clone the repository:
- bash
- git clone https://github.com/EmileGreyling/YouTube-Downloader-In-Flask.git

Navigate to the project directory:

bash
cd YouTube-Downloader-In-Flask
Create a virtual environment:

- bash
- python3 -m venv env

- Activate the virtual environment:

- On Windows:

- bash
- env\Scripts\activate
- On macOS and Linux:

- bash
- source env/bin/activate
- Install required dependencies:

- bash
- pip install -r requirements.txt
- Run the Flask application:

- bash
- flask run
- Open your web browser and go to:

- text
- http://127.0.0.1:5000
